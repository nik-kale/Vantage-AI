# @vantage-ai/engine

Optional AI/ML engine for in-browser analysis.

## Status

This package is currently a **stub/placeholder** for future AI capabilities.

## Planned Features

- In-browser SLM integration (WebLLM, Transformers.js)
- ONNX Runtime Web support
- WebGPU-accelerated inference
- Behavioral pattern recognition
- Privacy-preserving on-device analysis

## Contributing

We welcome contributions! Possible areas:

- Integrate Transformers.js for lightweight models
- Add ONNX Runtime Web support
- Implement WebGPU acceleration
- Create pre-trained models for common UX patterns
- Add benchmarking tools

See the root `CONTRIBUTING.md` for details.
